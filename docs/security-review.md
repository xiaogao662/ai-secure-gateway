`tests/test_session_revalidation.py` 已移除两个历史 xfail 标记，扩展为六个正常回归用例。已有有效会话的正常访问由原有聊天和角色权限测试覆盖。此次没有改变额度、登录限流或其他业务规则，没有调用付费模型。

## 历史发现（已修复）：工具执行前没有重新确认会话

位置：`app/routes/chat.py` 的 execute 回调（35–41 行）。请求入口验证会话，然后等待模型；回调只传原用户编号给网关。网关重新读取用户角色，但不读取原会话的撤销和过期状态。

本地确定性复现：管理员发起读取 Bob 材料，在模拟 provider 返回工具提议前，通过另一数据库会话提交撤销登录或设置会话过期。这里调用真实的撤销函数或修改临时测试会话，模拟等待期间发生变化，不依赖网络或耗时竞争。

| 等待期间发生的变化 | 原请求返回 | 后续检查 | 判定 |
| --- | --- | --- | --- |
| 原会话被撤销 | 200 / ALLOW，交付正文，审计 ALLOW | /auth/me 为 401 | 已复现撤销不约束在途工具执行 |
| 原会话已过期 | 200 / ALLOW，交付正文，审计 ALLOW | /auth/me 为 401 | 已复现过期不约束在途工具执行 |
| 管理员改为学生 | 403 / DENY，无正文 | 网关读到新角色 | 此对照场景正确拒绝 |

影响前提：攻击者必须先有有效会话并在失效前启动请求。不是任意匿名提权，也不能说明 alice 可以直接变成管理员。当前 UI 清空旧结果不等于服务器停止交付，直接 HTTP 客户端仍能获得响应。

优先级：P2（中等，建议在增加功能前修复）。如果产品明确允许已接收的请求继续执行，应收窄退出与过期承诺；本项目建议采用执行前有效的语义。修复方向：在模型返回之后、工具开始之前，用原会话凭证重新检查有效期、撤销状态和身份，失败则记录拒绝且不读取正文；不能相信模型传入的身份，也要防止数据库会话缓存掩盖变化。该检查本身不等于解决所有并发撤销的原子性问题。

复现文件：`tests/test_session_revalidation.py`。检查当天两个用例曾以 strict xfail 标识：xfail 表示已知问题导致预期失败，不是安全验证通过；这些标记现已移除。可运行 `python -m pytest tests/test_session_revalidation.py -q -s` 查看不含凭证或正文的结果摘要。

## 已确认的加固缺口，不等同于越权漏洞

2026-09-09 登录加固完成：密码校验前新增单进程滑动窗口限制，同一用户名每 60 秒最多 5 次、全局最多 20 次（成功和失败都算）；未知用户名同样处理。全局限制使轮换用户名不能无限触发密码校验，并限制活跃计数键数量。429 不创建或切换会话，已有会话不受影响；检查来源/参数失败不消耗该计数。登录尝试不依赖可伪造的 IP 请求头，未增加登录事件审计。重启清零、共享全局额度导致的临时拒绝服务、低速或分布式攻击等仍属于局限。下面“未设置”是检查当天的历史状态。

2026-09-09 模型限流更新：已新增真实身份绑定的每用户滑动窗口限制（最近 60 秒最多 5 次），在模型调用之前执行，超限返回 429 并记录审计。滑动窗口指每次检查过去 60 秒的记录，而不是整分钟统一清零。失败尝试也占用户次数；并发预留用锁保护，避免同时请求挤过上限；用户重新登录不能清零。不同用户独立计数，但单进程共享 20 次总上限仍存在，较长时间内一个用户仍可耗尽共享预算。下列描述保留风险背景，不代表完全解决资源消耗攻击。

1. 模型预算按进程共享（`app/agent/deepseek.py:62`）：20 次尝试能限制本次启动的费用，但单个已登录用户可以耗尽共享次数，影响其他用户；重启后预算重置。已有测试确认预算是共享的，没有执行真实费用耗尽攻击。后续可增加按用户的调用频率限制，保留全局上限。
2. 登录入口未设置尝试频率限制（`app/routes/auth.py:33`）：每次都进行密码验证。恶意客户端可以反复尝试密码或消耗密码校验资源；没有运行暴力猜测或压力测试。上线前需要增加频率限制，且不能只依赖可被伪造的用户名或请求头。演示账户密码本身是公开示例，不能用于生产。

## 检查到的现有保护

- 现有聊天与材料 HTTP 路径均调用网关；初始化脚本也会解密已有数据，但属于受信任本地操作，不是远程工具入口。
- 网关对工具使用固定允许清单，对参数拒绝额外字段；查询带有资源权限条件，通过授权才读取密文和解密。
- 可信用户编号由接口绑定，不接受模型传来的身份覆盖。
- 模型输出形状、单次工具数量和参数 JSON 有校验；模型自行编造的回答不会作为材料正文交付。
- 解密失败和审计写入失败不交付正文；模型传输错误返回固定错误码，而不返回原始供应商错误内容。
- 网页使用 textContent 展示动态文字，不把模型文字作为 HTML 执行。

这些是代码路径检查与既有测试覆盖，不代表所有异常、并发、侧信道或第三方依赖均已排除风险。
