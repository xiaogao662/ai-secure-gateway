## 提交前再检查一次

```powershell
.\.venv\Scripts\python.exe -m scripts.check_release --list
```

该命令只读检查候选文件，输出文件清单，以及疑点的文件名、行号、规则名，不输出匹配内容；图片仍需人工检查。候选清单不是 Git 暂存区，也不是保证没有秘密的证明。

用户确认仓库选项后，再初始化本地 Git、明确添加候选目录，检查实际待提交文件清单、文件内容和排除规则。暂存区就是准备进入下一次提交的文件集合。首次确认无误后再提交及推送；若出现真实凭证，不应继续发布，应处理凭证泄露风险和历史记录。

## 上传后的验收

1. 用新目录下载，按 README 初始化新的虚构数据与密钥，不复制个人密钥。
2. 确认网页、Mock 正常访问与拒绝可演示。
3. 检查 GitHub 上没有密钥、数据库或个人配置，图片和文档链接正常。
4. 如需 DeepSeek，使用自己的 API 密钥；模拟模式验收无需付费模型。

本项目当前使用公开演示密码、单进程限流和本机 HTTP 配置，不应直接暴露为公网服务。发布源码与部署在线服务是两件不同的事。
